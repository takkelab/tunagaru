# 画面

UIの実装は `src/web/` に置く。webが依存してよいのは `src/shared/contract/` のみ（[architecture](architecture.md#lintで強制する設計ルール)）。

## 画面一覧

| #   | 画面             | 役割                                                           |
| --- | ---------------- | -------------------------------------------------------------- |
| S1  | 検索             | 人物名・作品名で検索する。起点の入口                           |
| S2  | 候補の選択       | 同名の別人や、作品の作り手の候補から1人を選ぶ                  |
| S3  | グラフキャンバス | メイン画面。展開・折り畳み・ピン留め・経路の強調表示           |
| S4  | 根拠パネル       | 線やノードの根拠（引用・出典）を読み、承認・却下・マークを行う |
| S5  | 調査ダイアログ   | 「この人を調査」の設定、見積もり、進捗を表示する               |
| S6  | 未確認の線の一覧 | `unverified` の線をまとめてレビューする                        |
| S7  | 名寄せ待ちの一覧 | `pending_resolution` の線の相手を確定する                      |
| S8  | 予算と設定       | 当月の使用額、モデル、為替、表示の切り替え                     |

## S1 検索

- 入力欄は1つ。種別（人物／作品）は自動で判定し、切り替えもできる。
- 結果は「ローカルDBにある人物」を先に、「Wikidataの候補」を後に並べる。
- 作品で検索した場合は、作品ごとに作り手の候補を**役割つき**で表示する（著者、作詞、作曲、歌唱、バンド）。選ぶのは人物またはグループ。
- 一度選んだ起点は「最近の起点」として表示する（localStorageで十分）。

## S2 候補の選択

- 各候補には、Wikidataの説明文、生没年、職業、代表作を最大3件まで表示する。同名の別人を見分けるための情報。
- 該当する候補がない場合は「ローカル人物として作成」を選べる（QIDなし）。
- 既存の人物と同一だと気づいた場合は、S4から統合する（[data: 名寄せ](data.md#名寄せ)）。

## S3 グラフキャンバス

Cytoscape.js と fcose レイアウトを使う（[ADR 0008](../decisions/0008-expanding-canvas-forward-only.md)）。

### 線の表現

| 状態                                                                | 見た目                                                                                                                                      |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `approved`（本人が承認）                                            | 実線                                                                                                                                        |
| `unverified`（引用照合は通過、未承認）                              | 破線                                                                                                                                        |
| `attribution = third_party`                                         | 線の色を変え、凡例で「第三者の記述」と示す。表示するかは [ADR 0006](../decisions/0006-source-and-model-selection-by-evaluation.md) で決める |
| `origin = wikidata`                                                 | 実線扱い。根拠パネルにWikidataへのリンクを出す                                                                                              |
| `past_like`                                                         | 既定では非表示。S8で表示に切り替えると点線になる                                                                                            |
| `rejected` / `dislikes` / `denies_influence` / `pending_resolution` | 表示しない                                                                                                                                  |

線の向きは「好きな側 → 好かれている側」。表示するのは**順方向のみ**。

### ノードの表現

- 人物は丸、グループは角丸の四角で表す。
- マークのバッジ: 好き＝♥、気になる＝☆、試した＝✓、合わなかった＝×。
- 合流ハイライト: 自分が「好き」にした人物の2人以上から線が来ているノードを強調する。強調の強さは、線が来ている人数に比例させる。
- 「+N」バッジ: まだ表示していない子ノードの数。

### 展開のルール

- ノードをクリックすると、子ノードを**最大20件**表示する。残りは「+N」になり、押すと20件ずつ追加する。
- 並び順（[data: 並び順](data.md#並び順)）:
  1. 合流スコアの降順
  2. 承認済みを先に
  3. 出典数の降順
  4. 「合わなかった」とマークした人物の先は減点する
- 同じ人物がすでに画面にある場合は、新しいノードを作らず、既存のノードに線を引く。
- 折り畳み: 展開した子ノードを畳む。ただし、他の経路からもつながっている子ノードは残す。
- ピン留め: レイアウトの再計算でノードが動かないようにする。
- 経路の強調表示: ノードを選ぶと、起点からそのノードまでの最短経路を強調する。
- 行き止まりのノード（順方向の線が0本）では、「この人を調査」ボタンを目立たせる。順方向のみの表示では、時代をさかのぼるほど行き止まりが増えるため（[ADR 0008](../decisions/0008-expanding-canvas-forward-only.md)）。

### グループ

- グループを展開すると、グループ自身の線に加えて、メンバー個人の線も集約して表示する。線は**発言した個人**から引き、ラベルに発言者の名前を出す（例: 「草野正宗 → X」）。
- メンバーは、グループのノードから「メンバーを表示」で出す。

## S4 根拠パネル（右ドロワー）

### 線を選んだとき

- 好きな側・好かれている側・極性・発言者の区別（本人／第三者）
- 根拠の一覧: 引用（最大200字）、出典URL（新しいタブで開く）、出典の種類、取得日。作品への言及があれば作品名、訳文があれば訳文
- 操作: 承認、却下（理由を1行で書ける）
- 却下した線は、同じ引用で再抽出されても復活しない（[data: 却下の維持](data.md#却下の維持)）

### ノードを選んだとき

- 名前と別名、Wikidataへのリンク、所属グループとメンバー
- 状態マーク（好き／気になる／試した／合わなかった）
- 外部リンク:
  - Wikipedia（ja／en）
  - Spotify・Apple Musicの検索（音楽家の場合）
  - Amazon・カーリルの検索（作家の場合）
  - 職業から判定できない場合は、すべて表示する
- 「この人を調査」（S5を開く）
- 「別の人物と統合」

## S5 調査ダイアログ

- ソースの選択: 選べるのは [ADR 0006](../decisions/0006-source-and-model-selection-by-evaluation.md) で採用されたソースのみ。URLとテキストは貼り付け欄から入力する。
- 実行前の表示: 見積もり費用（円）と予算の残り（円）。見積もりが残りを超える場合は、実行ボタンを無効にし、理由を表示する。
- 実行中の表示: 本文の取得、事前フィルタ、抽出、照合、名寄せの各段階と、照合で捨てた件数。画面を閉じても、ジョブは裏で継続する。
- 完了後の表示: 新しく増えた線の数（未確認・名寄せ待ちの内訳）と実費。

## S6 未確認の線の一覧

- 未確認の線を、人物ごとにまとめて表示する。引用と出典を並べ、1件ずつ、またはまとめて承認・却下する。
- キーボード操作に対応する（`a` で承認、`r` で却下、`j`/`k` で移動）。

## S7 名寄せ待ちの一覧

- LLMが返した名前と、Wikidataの候補（最大5件）を並べる。
- 本人が1人を選ぶか、ローカル人物を作るか、破棄する。確定した線は `unverified` になる。

## S8 予算と設定

- 当月の使用額と上限（円とドル）、予約中の額、調査1回あたりの平均額、キャッシュヒット率
- 設定項目: モデル（既定は `claude-haiku-5-5`）、為替レート（初期値は150円/$）、月の上限（初期値は500円）、`past_like` の表示

## 状態と異常時の表示

| 状況              | 表示                                                                                         |
| ----------------- | -------------------------------------------------------------------------------------------- |
| 検索結果が0件     | 「見つかりませんでした」と、ローカル人物の作成への導線                                       |
| 展開しても線が0本 | 行き止まりの表示と調査ボタン                                                                 |
| 調査中            | ノードにスピナーを表示する。他の操作はできる                                                 |
| 予算超過          | 調査系のボタンを無効にし、理由（今月の残額）を表示する                                       |
| 外部APIの障害     | 「Wikidataに接続できません」のように、どこが失敗したかを表示する。ローカルDBの表示は継続する |
| 名寄せ待ちがある  | ヘッダーにS7の件数バッジを表示する                                                           |
