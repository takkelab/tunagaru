# 画面

UIの実装は `src/web/` に置く。webが依存してよいのは `src/shared/contract/` のみ（[architecture](architecture.md#lintで強制する設計ルール)）。

主役は、好きな人たち（起点）の「好き」を横に並べたときに浮かび上がる**重なり**と、元の記事・動画への**案内**（[ADR 0022](../decisions/0022-overlaps-of-seed-people-as-core.md)）。グラフキャンバスは作らない。

## 画面一覧

| #   | 画面             | 役割                                                                       |
| --- | ---------------- | -------------------------------------------------------------------------- |
| S1  | 起点の追加       | 好きな人を名前で検索し、起点として追加する                                 |
| S2  | 候補の選択       | 同名の別人から1人を選ぶ                                                    |
| S3  | 重なりの一覧     | メイン画面。2人以上の起点が好きと言っている作り手を、カードで並べる        |
| S4  | 棚               | 起点1人の「好きなもの」の一覧。1人しか挙げていないもの（意外）はここで見る |
| S5  | 根拠パネル       | 根拠を読み、元の記事・動画の該当箇所へ飛ぶ。確認・却下を行う               |
| S6  | 調査ダイアログ   | 記事のURLや動画の文字起こしを入れて調べる。見積もりと進捗を表示する        |
| S7  | 名寄せ待ちの一覧 | `pending_resolution` の線の相手を確定する                                  |
| S8  | 予算と設定       | 当月の使用額、モデル、為替、外部リンクの選択、表示の切り替え               |
| S9  | 気になる作品     | 「気になる」を付けた作品の一覧と、店・配信サービスへのリンク               |

## S1 起点の追加

- 入力欄は1つ。人物名かグループ名で検索する。
- 結果は「ローカルDBにある主体」を先に、「Wikidataの候補」を後に並べる。
- 選んだ主体を起点に追加する（`entity.seed_at` を設定する）。起点は外すこともできる（線と根拠は消さない）。
- 主体は誰でもよい（作家、音楽家、俳優など）。

## S2 候補の選択

- 各候補には、Wikidataの説明文、生没年、職業、代表作を最大3件まで表示する。同名の別人を見分けるための情報。
- 該当する候補がない場合は「ローカル人物として作成」を選べる（QIDなし）。

## S3 重なりの一覧

並び順は [data: 重なり](data.md#重なり) のとおり。

### 重なりのカード

- 作り手の名前と、重なりの数（例: 「3人」）、確認の数（例: 「確認 1/3」）。
- 起点ごとの行: 起点の名前、挙げた作品（なければ「作家として」）、根拠の引用（本人の言葉）、元の記事・動画へのリンク（動画は「▶ 12:34 から」）。行を選ぶと S5 を開く。
- 作品が1つも挙がっていなければ、代表作を「入口の候補」として、根拠の行とは分けて出す。
- 作品の横に「気になる」のボタン（☆）を出す。
- 未確認の根拠しかない行には「未確認」の表示を付ける。
- 間違いが起きやすい根拠（あいまい一致で照合したもの、`third_party` の記述）には、小さな「要注意」の印を付ける。
- 有名な作家も下げたり削ったりしない（[ADR 0022](../decisions/0022-overlaps-of-seed-people-as-core.md)）。
- カードの「まとめて確かめる」で、そのカードの未確認の根拠を順に S5 で開く。

### 一覧の上部

- 起点の数と、重なりの数。
- 起点がまだ2人未満のときは、S1 への導線を出す。
- 起点の一覧（名前を選ぶと S4 を開く）。まだ「好き」が見つかっていない起点には、調査ボタンを目立たせて出す。

## S4 棚

- 起点1人の「好きなもの」を作り手ごとに並べる（並び順は [data: 重なり](data.md#重なり)）。
- 棚は**本人の言葉を読む場所**にする。各行の主役は根拠の引用（本人の言葉、最大200字）で、作り手の名前、挙げた作品、出典へのリンクを添える。名前だけの一覧にはしない。驚くのと確かめるのが同時に起きるようにするため（[ADR 0022](../decisions/0022-overlaps-of-seed-people-as-core.md)）。
- 各行に「未確認」の表示と、S3 と同じ「要注意」の印、重なっている場合はその人数を出す。
- その起点の根拠になった記事・動画の一覧（タイトル、取得日、見つかった「好き」の数）。
- 「この人を調査」（S6 を開く）。
- 外部リンク: Wikipedia（ja／en）。
- 別名の追加: ソロプロジェクトの名義や表記揺れを、起点の別名として追加できる。追加すると、名寄せ待ちのうちその別名に一致するものが、この起点に寄る（[ADR 0023](../decisions/0023-works-as-records-overlaps-by-creator.md)）。

## S5 根拠パネル（右ドロワー）

### 根拠を選んだとき

- 好きな側・好かれている側・極性・発言者の区別（本人／第三者）。
- 根拠の一覧。1件ごとに次を出す。
  - 引用（本文側の文字列、最大200字）と、その前後の文脈（各100字程度。本文のキャッシュから切り出す）
  - あいまい一致で照合したものには「文字起こしと照合」の表示
  - 出典: タイトル、URL（新しいタブで開く）、取得日。動画は `t=<秒>s` つきのリンクで、その場面から再生する
  - 作品への言及があれば作品名、訳文があれば訳文
- 操作: 確認（`approved` にする）、却下（理由を1行で書ける）。
- 却下した線は、同じ引用で再抽出されても復活しない（[data: 却下の維持](data.md#却下の維持)）。
- キーボード操作に対応する（`a` で確認、`r` で却下、`j`/`k` で次と前の根拠）。

### 作品を選んだとき

- 題名、作り手（役割つき）、Wikidataへのリンク。
- 「気になる」の切り替え。
- 外部リンク: S8 で選んだ店・配信サービスの検索URL（初期値は、本なら Amazon、音楽なら Spotify）。
- 作品が確定していない根拠（`work_title_raw` だけのもの）では、作品の候補から選んで確定できる。

## S6 調査ダイアログ

- 入力（ステップ5）:
  - 記事のURL
  - 動画のURLと、YouTube の「文字起こしを表示」からコピーした文字列（[data: 文字起こし](data.md#文字起こし)）
  - テキストの貼り付け（出典のURLかラベルを付ける）
- 自動調査（ステップ8）: 「記事を探す」を選ぶと、Web検索で記事のURLを探し、上と同じ経路で調べる。検索する語の一覧を、実行前に表示する。
- 実行前の表示: 見積もり費用（円）と予算の残り（円）。見積もりが残りを超える場合は、実行ボタンを無効にし、理由を表示する。
- 実行中の表示: 検索、本文の取得、事前フィルタ、抽出、照合、名寄せの各段階と、照合で捨てた件数。画面を閉じても、ジョブは裏で継続する。
- 完了後の表示: 新しく見つかった「好き」の数（未確認・名寄せ待ちの内訳）、新しく生まれた重なり、実費。見つからなければ「URLか文字起こしを貼れば調べます」と表示する。

## S7 名寄せ待ちの一覧

- LLMが返した名前と、Wikidataの候補（最大5件）を並べる。
- 本人が1人を選ぶか、ローカル人物を作るか、破棄する。確定した線は `unverified` になる。
- 選んだ候補には、LLMが返した名前を別名として登録できる（自動字幕の誤記を吸収するため）。

## S8 予算と設定

- 当月の使用額と上限（円とドル）、調査1回あたりの平均額、キャッシュヒット率
- 設定項目: モデル（既定は `claude-haiku-5-5`）、為替レート（初期値は150円/$）、月の上限（初期値は500円）、`past_like` の表示、外部リンクの店・配信サービス（本と音楽で1つずつ選ぶ）

## S9 気になる作品

- 「気になる」を付けた作品を、付けた日の新しい順に並べる。
- 各作品に、作り手、その作品を挙げた起点、外部リンクを出す。

## グループ

ステップ10で実装する（[ADR 0023](../decisions/0023-works-as-records-overlaps-by-creator.md)）。

- グループとメンバーは別の主体にする。線は**発言した個人**から引き、表示では発言者の名前を出す（例: 「草野正宗（スピッツ）」）。
- 起点がグループの場合は、メンバーの線もそのグループの線として重なりを数える。

## 状態と異常時の表示

| 状況                    | 表示                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| 起点が0人               | S1 への導線                                                                                  |
| 重なりが0件             | 「まだ重なりはありません」と、起点ごとの「好き」の数と、調査ボタン                           |
| 起点の「好き」が0件     | その起点に調査ボタンを目立たせて出す                                                         |
| 調査中                  | 起点の名前の横にスピナーを表示する。他の操作はできる                                         |
| 予算超過                | 調査系のボタンを無効にし、理由（今月の残額）を表示する                                       |
| 外部の障害              | 「Wikidataに接続できません」のように、どこが失敗したかを表示する。ローカルDBの表示は継続する |
| URLの本文を取得できない | 「本文を取得できませんでした。テキストを貼り付けてください」と、貼り付けへの導線             |
| 名寄せ待ちがある        | ヘッダーにS7の件数バッジを表示する                                                           |
