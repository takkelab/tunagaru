# 0003 抽出は明示ボタンで起動し、結果を永続キャッシュする

- 状態: 採用
- 日付: 2026-11-15

## 背景

ノードを展開するたびに「検索 → 本文の取得 → LLMで抽出」を行うと、1回あたり10〜30秒かかり、その都度課金も発生する。

## 決定

- 展開したときは、ローカルDB（キャッシュと構造化データ）にあるものだけを即座に表示する。
- 「この人を調査」ボタンを押したときだけ、非同期のジョブでLLM抽出を行う。
- 抽出結果は `content_hash × model × prompt_version` をキーに永続化し、同じ本文は二度とLLMに送らない。

## 検討した代替案

- 展開ごとに自動で抽出: 体験はなめらかだが、遅延と費用が予測できない。
- 事前のバッチ処理のみ: 未知の人物には対応できない（補助としてはステップ10で採用する）。

## 結果とトレードオフ

- 初めて見る人物では、線が出るまでに1操作増える。そのため、行き止まりのノードでは調査ボタンを強調する（[screens](../spec/screens.md#展開のルール)）。
- プロンプトを変えると `prompt_version` が変わり、キャッシュが無効になる（意図したとおりの動作）。
