# 0016 AGENTS.mdを正とし、ディレクトリごとに指示ファイルを置く

- 状態: 採用
- 日付: 2026-11-15

## 背景

将来、Claude Code 以外のエージェント（Codex など）も使う可能性がある。openai/codex では、指示ファイルを階層的に置き、近いものを優先する運用をしている。ルートの指示ファイルは、長くなるほど読まれなくなる。

## 決定

- ルートの `AGENTS.md` を正とし、`CLAUDE.md` には `@AGENTS.md` の1行だけを書く。
- ルートは50行以内とし、SPEC への導線、コマンド、進め方へのリンク、禁止事項だけを書く。
- `src/domain`／`src/app`／`src/adapters`／`src/web` に、10行程度の `AGENTS.md` を置く。
- lint やテストで強制できることは、指示ファイルに書かない。

## 検討した代替案

- CLAUDE.md のみ: Claude Code のフックやスキルとは連携しやすいが、他のツールで再利用できない。

## 結果とトレードオフ

- 指示ファイルが分散するので、[architecture](../spec/architecture.md#指示ファイルagentsmd) に置き方の方針を書いておく。
