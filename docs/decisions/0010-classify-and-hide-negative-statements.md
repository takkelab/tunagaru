# 0010 否定は分類して保存し、表示はしない

- 状態: 採用
- 日付: 2026-11-15

## 背景

「嫌い」「昔は好きだった」「影響を否定している」といった発言は、読み分けないと「好き」の線として誤って登録される。

## 決定

- 極性を `likes`／`influenced_by`／`past_like`／`dislikes`／`denies_influence` に分類して保存する（[data](../spec/data.md#polarity極性)）。
- グラフに出すのは `likes` と `influenced_by` だけ。`past_like` は設定で表示できる。
- 否定の線も保存しておき、同じ発言を再抽出しても「好き」として誤登録されないようにする。

## 検討した代替案

- 「好き」以外は捨てる: 実装は単純だが、再抽出で誤りが復活しやすい。
- 否定も赤い線で表示する: 発見の役に立たず、画面がうるさくなる。

## 結果とトレードオフ

極性の分類精度は、評価で測る（[metrics](../spec/metrics.md#抽出の品質)）。
