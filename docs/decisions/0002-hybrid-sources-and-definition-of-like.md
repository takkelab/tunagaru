# 0002 データ源はハイブリッド、「好き」は本人の公言に限る

- 状態: 採用
- 日付: 2026-11-15

## 背景

「AさんがBさんを好き」というデータは、構造化データにはほとんどない。Wikidata の P737（influenced by）は正確だが件数が少なく、日本の作家はほぼ載っていない。LLMで抽出すれば件数は増えるが、もっともらしい誤りが混ざる。また「好き」の範囲を広げるほど、グラフは密になるが、意味は薄れる。

## 決定

- データ源: 構造化データ（Wikidata・MusicBrainz）、本文からのLLM抽出（出典必須）、手動の追加を組み合わせる。
- 「好き」の定義: **本人が公言した影響・愛好**に限る。推薦・帯コメント、カバー・オマージュ・共作、アルゴリズムによる類似は含めない。
- 対象は本と音楽で、ジャンルをまたぐ線も扱う。人物は単一の「主体」型にする。

## 検討した代替案

- 構造化データのみ: 正確だが、日本の作家やマイナーな作家ではほぼ線がない。
- LLM中心（本文なしで質問する）: 捏造のリスクが高い。
- ユーザー投稿中心: 最初はデータが空になる（コールドスタート）。
- 類似アーティストを含める: 「好き」ではなく「似ている」なので、別物として扱う。

## 結果とトレードオフ

- 線の数は少なめになるが、根拠を示せる。
- Wikipediaの「影響を受けた」節のような第三者の記述を、どう扱うかが残る（`attribution` で区別する。[ADR 0006](0006-source-and-model-selection-by-evaluation.md)）。
