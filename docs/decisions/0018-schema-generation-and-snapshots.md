# 0018 スキーマ生成とずれ検知、スナップショットテスト

- 状態: 採用
- 日付: 2026-11-15

## 背景

API契約とLLMの出力スキーマが黙って変わると、web・server・抽出器の間で不整合が起きる。プロンプトの小さな変更も、抽出の品質に大きく効く。openai/codex では、スキーマをfixtureとして生成してコミットし、スナップショットテストで出力の変化を差分として見せている。

## 決定

- `src/shared/contract/` の Zod スキーマから、JSON Schema を `schema/` に生成してコミットする。`pnpm check` でずれを検出する（[api](../spec/api.md#契約とスキーマのずれ検知)）。
- プロンプトの全文、CLIの出力、評価レポートの形式を、スナップショットテストの対象にする（[testing](../spec/testing.md#スナップショット)）。

## 検討した代替案

- 型の共有だけで済ませる: TypeScript の型は実行時やレビューの差分には現れないため、変化に気づきにくい。

## 結果とトレードオフ

- スキーマやプロンプトを変えるたびに、生成物とスナップショットの更新が必要になる（それがレビューの材料になる）。
