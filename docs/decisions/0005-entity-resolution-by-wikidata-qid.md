# 0005 名寄せはWikidata QIDを正とし、統合は手動で行う

- 状態: 採用
- 日付: 2026-11-15

## 背景

「村上春樹」と「Haruki Murakami」は同一人物だが、同姓同名の別人もいる。ペンネーム、バンドとメンバー、共同筆名などのケースもある。名寄せを誤ると、グラフ上で別人同士がつながってしまう。

## 決定

- Wikidata の QID があれば、それを正とする。候補が1件に決まらなければ、本人が選ぶ（`pending_resolution`）。
- QIDのない人物はローカルIDで作り、後から統合できるようにする。統合元は `redirect_to` で残す。
- LLMによる自動の統合はしない。

## 検討した代替案

- 名前の完全一致のみ: 表記揺れで同じ人物が重複し、同名の別人が混ざる。
- LLMで自動判定: 誤って統合しても気づきにくく、後から直すのが大変。

## 結果とトレードオフ

- 名寄せ待ちの確定作業が発生する（[screens](../spec/screens.md#s7-名寄せ待ちの一覧) のS7）。
- 統合の処理（付け替えと重複した線の結合）は複雑なので、テストを厚くする（[process ステップ10](../spec/process.md#ステップ10-統合とグループstep10-merge-groups)）。
