# 0004 引用照合をして、未確認の線は破線で表示する

- 状態: 採用
- 日付: 2026-11-15

## 背景

LLMの抽出には捏造が混ざる。引用が本物であっても、「嫌いと言った」「インタビュアーが好きなだけ」のような読み違いは残る。

## 決定

- LLMに、本文からそのまま抜き出した引用を出させる。正規化した本文の部分文字列でない引用は、自動で破棄する（[data](../spec/data.md#引用照合)）。
- 照合を通った線は `unverified`（破線）とし、本人が根拠を読んで承認すると `approved`（実線）になる。

## 検討した代替案

- 全件を手動で承認するまで表示しない: 確実だが、承認しないかぎり何も見えず、辿る楽しさがなくなる。
- 自動で採用し、信頼度だけを表示する: 誤りがそのまま実線のように見えてしまう。

## 結果とトレードオフ

- 捏造はほぼ排除できるが、読み違いは本人のレビューに頼る。極性と発言者の分類（[ADR 0010](0010-classify-and-hide-negative-statements.md)）で減らす。
- 正規化が足りないと、本物の引用まで捨ててしまう（破棄率を [metrics](../spec/metrics.md#抽出の品質) で監視する）。
