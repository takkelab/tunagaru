# 0001 個人用ローカルWebアプリにする

- 状態: 採用
- 日付: 2026-11-15

## 背景

利用者は本人だけ。APIキーを使い、本人の予算で外部APIを呼ぶ。

## 決定

PCのローカルで、Webアプリ（`127.0.0.1` へのbindとSQLite）として動かす。デプロイ、認証、マルチユーザー、スマホ対応はスコープ外とする。将来デプロイできるように、DBアクセスはアダプタに閉じ込めておく。

## 検討した代替案

- 公開Webサービス: 認証、不正利用対策、利用規約への対応が必要になり、個人開発には重い。
- 最初からデプロイ（Cloudflare・Vercel＋Turso）: スマホから使えるが、URLが漏れると本人の予算で調査を実行されてしまう。認証を作るまでは危険。
- スマホアプリ・デスクトップアプリ: グラフをタッチで操作するUIや配布の手間が増える。

## 結果とトレードオフ

- 外出先やスマホからは使えない。
- 認証がない分、`0.0.0.0` にbindしないことをテストで保証する（[process ステップ6](../spec/process.md#ステップ6-api層step06-api)）。
